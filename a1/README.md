# A-1 · هيكل التطبيق بالتصميم «د»

عرض DEMO مستقل داخل نفس الأصل، للأدوار الستة فقط. افتح `/a1/`، أو
`/a1/?role=ph&lang=en&theme=dark`. الأدوار: `ph`, `lead`, `sup`, `dir`, `prog`, `req`.

- الرئيسية: الترويسة والبحث، بطاقة التركيز، الاختصارات، «بانتظارك»، بطاقات الخدمات، وأربع تبويبات حسب الدور.
- البحث محلي في الخدمات والسجلات التجريبية والشخص التجريبي نفسه، باستخدام `mil`.
- كل وجهة خارج الرئيسية/البحث/بانتظارك تعرض حدود المرحلة؛ لا تفاصيل طلبات أو قرارات أو إرسال أو تعديل سجلات.
- `data.mjs` يجمع افتراضيات العرض والإعدادات والبيانات التجريبية. توصيلها بإعدادات اللوحة مؤجل إلى اعتماد المرحلة المناسبة.
- `app.mjs` يستخدم DOM ونصوصاً دون `innerHTML`، مع CSP تمنع الاتصالات والعمال والنماذج. تبديل دور العرض لا يمنح صلاحيات.
- يستخدم قاعدة IndexedDB تجريبية منفصلة `gpt-a1-demo` لمعرّفات السجلات المضمّنة فقط. البيانات تظهر مباشرة من الحزمة قبل انتظار التخزين. لا يقرأ جلسات أو بيانات دخول التطبيق.

## التشغيل والفحص

من جذر المستودع: `python -m http.server 4173` ثم افتح `http://localhost:4173/a1/`.

```sh
node --test a1/tests/model.test.mjs
npm ci --prefix .github/tools
.github/tools/node_modules/.bin/playwright install chromium
A1_REFERENCE_DIR=/path/to/reference-files node --test --test-concurrency=1 a1/tests/browser.test.mjs
```

مجلد المراجع للاختبار يحتوي `app.html` و`panel.html` من فرع `gpt-ref` فقط.
الفحص `A1 DEMO review` يشغّل المرجعين في Chromium ويولّد 96 لقطة للتطبيق
(6 أدوار × لغتين × وضعين × عرضين × موضعي تمرير) ولقطتين للمرجع،
مع حجب كل طلب خارج خادم الفحص. لا يُشغّل أي فحص ضد n8n أو صفحة الدخول الحية.

## حدود التكامل المطلوب مراجعتها

المستودع العام يحتوي نواتج النشر المجمّعة فقط. لذلك هذه المرحلة توفر هيكلًا قابلًا للفحص في `/a1/`،
ولا تستبدل الحزمة الحية أو تدخلها عبر تعديل ملف ذي اسم مشتق من المحتوى. يلزم نقل الوحدة إلى مصادر
البناء الأصلية وربطها بمسار DEMO الرسمي قبل اعتمادها كتغيير للتطبيق الرئيسي.

ملفات الدخول والتوقيع والتخزين الأصلي و`sw.js` ورقم الإصدار لم تتغير. الفتح الأول دون شبكة
وإضافة ملفات A-1 إلى مخزون Service Worker غير مُنفذين؛ يحتاجان تغييرًا مصرحًا به في دورة النشر.
لا يوجد خادم أو إعداد لوحة أو صلاحيات حقيقية في هذه المرحلة.
